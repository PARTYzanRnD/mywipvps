# Установка XHTTP с Marzban

Обычная установка запускается через `sudo bash vps-setup-xhttp-marzban.sh`.

Для установки или переустановки Marzban рядом с существующим контейнером Caddy выполните команду ниже.

```bash
sudo bash vps-setup-xhttp-marzban.sh --reuse rosgospalec.work.gd
```

Режим рассчитан на схему, в которой Xray занимает TCP `443` и передаёт HTTPS в Caddy на `127.0.0.1:4123` с PROXY protocol. Caddy должен работать в сети хоста, проксировать PhotoHunt и иметь bind mount для сокета Marzban. При первой установке порт `443` должен быть свободен. Нужны работающий локальный Docker, Compose и системные команды `curl`, `ss`, `flock`, `openssl`, `python3`. Каталог данных Marzban и `/opt/xray-vps-setup` должны быть на одной файловой системе.

Новый проект использует Marzban `v0.8.4`, Xray `26.3.27` и новую SQLite с администратором. Старые пользователи и подписки остаются в резервной копии. Во время переключения публичный HTTPS недоступен. При успешном запуске скрипт сообщает путь к каталогу проекта с закрытым `admin.env` и резервной копией `backup/`. Путь панели указан в `DASHBOARD_PATH` в файле `live.json`. Прежний контейнер сохраняется остановленным с отключённым автозапуском. Повторный запуск проверяет готовность активного проекта.

При ошибке переключения скрипт возвращает прежнюю SQLite и запускает прежний контейнер. Если процесс принудительно прерван или откат завершился ошибкой, ссылка `/opt/xray-vps-setup/marzban-reuse/pending` указывает на каталог операции. В нём находятся `backup/` и `previous` с ID и политикой перезапуска старого контейнера. Последующие запуски заблокированы до восстановления состояния.
